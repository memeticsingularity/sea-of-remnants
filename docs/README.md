# docs/ — 项目文档

本目录存放项目级文档，包括需求、计划、进度和规范，与代码分离但受版本控制。

## 子目录索引

- [`requirements/`](requirements/README.md) — 需求池与功能列表
- [`plans/`](plans/README.md) — 架构设计与方案文档
- [`progress/`](progress/README.md) — 里程碑、任务清单与变更日志
- [`conventions/`](conventions/README.md) — 命名、写作、UI 规范

## 使用方式

- 新增需求时写入 `requirements/features.md`。
- 重大设计决策写入 `plans/`。
- 每个阶段完成后更新 `progress/`。
- 编码前阅读 `conventions/` 确保风格一致。
