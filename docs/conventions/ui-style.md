# UI 风格约定

## 主题

- 暗色主题为主。
- 背景色：`#0a0a0f`
- 卡片背景：`#13131f`
- 卡片高亮背景：`#1c1c2e`
- 边框色：`#2e2e45`

## 颜色

- 主强调色（霓虹紫）：`#d946ef`
- 次强调色（青色）：`#06b6d4`
- 金色（稀有度）：`#f59e0b`
- 正面数值：`#22c55e`
- 负面数值：`#ef4444`
- 主文本：`#e2e8f0`
- 次要文本：`#94a3b8`
- 暗淡文本：`#64748b`

## 布局

- 左侧固定侧边栏（宽度 224px）。
- 顶部搜索栏。
- 主内容区可滚动。
- 卡片网格：移动端 1 列，平板 2 列，桌面 3 列。

## 组件

### 卡片

- 圆角 `rounded-lg`
- 边框 `border border-border`
- 背景 `bg-surface`
- hover 状态：`hover:border-accent/50`

### 标签

- 默认：灰底白字
- accent：紫底紫字
- cyan：青底青字
- gold：金底金字

### 术语提示

- 术语使用虚线下划线 `border-b border-dotted border-accent-cyan`
- 文字颜色 `text-accent-cyan`
- hover 显示浮动提示框

## 响应式

- 移动端：侧边栏可收起（Phase 2 实现）
- 小屏幕：卡片单列
- 大屏幕：卡片三列
