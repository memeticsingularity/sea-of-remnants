# Bug 记录

本目录按编号记录项目开发过程中发现的 bug、原因分析与修复方案。

## 记录格式

每个 bug 一个文件，命名规则：`bug-XXX.md`

文件内容包含：

1. **表现** — bug 的具体现象
2. **原因** — 根因分析
3. **修复方案** — 如何修复
4. **相关文件** — 修改了哪些文件
5. **状态** — 已修复 / 待修复 / 观察中
