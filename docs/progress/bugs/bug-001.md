# Bug #001 — 术语 tooltip 中二级术语无法 hover / 遮挡父 tooltip

### 表现

当鼠标 hover 到正文中的一级术语（如“灵感”）时，会弹出该术语的解释框。解释框内部如果包含另一个术语链接（如“[加料]”），存在两个问题：

1. 鼠标移向二级术语时，一级 tooltip 可能立即消失。
2. 二级术语的 tooltip 直接覆盖在一级 tooltip 上方，遮挡父级解释。

### 原因

1. 一级 tooltip 使用绝对定位显示在术语上方，与术语文字之间存在视觉间距（`mb-2`）。鼠标从术语移向 tooltip 时会经过间隙，触发 `onMouseLeave` 导致 tooltip 关闭。
2. 嵌套的二级 tooltip 默认也显示在术语上方，因此会覆盖其父 tooltip。

### 修复方案

采用“链条式” tooltip 设计：

1. **桥接层**：在术语与 tooltip 之间添加透明桥接层，覆盖间隙，保持 hover 状态。
2. **方向区分**：
   - 正文中的术语：tooltip 向上弹出（`bottom-full`）。
   - tooltip 内部的术语：tooltip 向下弹出（`top-full`），形成上下链条，避免遮挡父 tooltip。

```tsx
// 正文术语：向上弹出
const topTooltip = 'absolute bottom-full left-1/2 ...'

// tooltip 内部术语：向下弹出，形成链条
const bottomTooltip = 'absolute top-full left-1/2 ...'
```
