# Bug #002 — 技能卡片中术语 tooltip 无法显示

### 表现

在技能列表页（`/skills`）的 SkillCard 中，技能短描述里的术语（如“灵感”）虽然被高亮显示，但鼠标 hover 时无法弹出术语解释框。

### 原因

SkillCard 的描述文本使用了 Tailwind 的 `line-clamp-2` 类进行两行截断。`line-clamp` 会创建一个块级格式化上下文并裁剪溢出内容，导致包裹在内部的 GlossaryTooltip 的绝对定位弹窗被裁剪或无法响应鼠标事件。

### 修复方案

1. 移除 SkillCard 描述文本的 `line-clamp-2` 类，让文本自然换行，避免 tooltip 被裁剪。
2. 调整卡片结构：不再将整个卡片包裹在 `<Link>` 中，仅将标题区域作为链接，描述区域的术语 tooltip 不再受 `<Link>` 事件捕获影响。

```tsx
// 修复后结构
<Card hover className="h-full">
  <Link to={`/skills/${skill.slug}`}>
    <h3 className="text-lg font-bold text-text hover:text-accent">{skill.name}</h3>
  </Link>
  <p className="text-sm text-text-muted">
    <GlossaryTooltip text={skill.shortDesc} />
  </p>
</Card>
```
