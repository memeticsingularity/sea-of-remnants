# Bug #003 — 术语表 hash 锚点跳转无滚动 + related 关联缺乏依据

### 表现

1. 在术语表页面（`/glossary`）点击某个术语的「相关」链接，或直接从带 hash 的 URL（如 `/glossary#glossary-mars-splash`）进入时，页面不会自动滚动到目标术语卡片。
2. 部分术语的 `related` 字段包含与定义正文无关的术语。例如：
   - 「附加伤害」的 related 包含「战意」「暴击率」，但其定义中并未提及。
   - 「火星飞溅」的 related 包含「战意」，但其定义中只提到「溅射」。

### 原因

1. **无滚动**：React 渲染术语列表是异步的，浏览器默认的 hash 滚动发生在 DOM 元素生成之前，因此目标卡片不存在，滚动失败。
2. **related 质量**：早期录入时相关术语靠人工联想，未与定义正文校验，导致关联缺乏依据。

### 修复方案

1. **滚动修复**：在 `GlossaryPage` 中使用 `useEffect` 监听 `location.hash`：
   - 找到目标术语后，若当前搜索筛选导致其不可见，则清空搜索框。
   - 目标可见后，调用 `el.scrollIntoView({ behavior: 'smooth', block: 'start' })` 平滑滚动。
2. **数据修复**：
   - 移除「附加伤害」中无依据的 related。
   - 移除「火星飞溅」中未在定义中出现的「战意」。
