# Bug #004 — 守护图鉴左右分栏布局错误

### 表现

守护图鉴页面（`/figurehead-prayer`）左右分栏不符合预期：

1. **左右堆叠而非并列**：左侧「已配置」面板与右侧图鉴在响应式布局下会上下堆叠，未做到始终并列。
2. **左侧面板错误**：左侧应显示「已配置」（`LoadoutPanel`，7 槽位），但被错误替换为「我的已拥有」（`OwnedGuardianPanel`），后者是本页面不需要的组件。
3. **联动开关位置不当**：联动/独立开关应位于左侧「选择分支」面板顶部，与分支选择按钮同区域。

### 原因

1. **网格布局使用响应式断点**：`grid-cols-1 lg:grid-cols-12` 在小屏下退化为单列，左右堆叠。正确做法是使用固定列数（24列），永不堆叠。
2. **混淆"已有"与"已配置"**：「左边已有」在游戏语境中指"已配置的栏位"（equipped loadout），而非"已拥有的守护集合"（owned collection）。前者是 7 槽位配置面板，后者是已收集列表。
3. **对布局需求理解偏差**：未理解页面核心需求是「左边已配置 + 右边图鉴」始终并列的 24 列网格布局。

### 修复

1. 改用固定 24 列 CSS Grid：`grid-cols-[repeat(24,minmax(0,1fr))]`，无响应式断点。
2. 左侧 `col-span-8`：选择分支 Card（含联动开关 + 3 个分支按钮）+ `LoadoutPanel`（7 槽位）。
3. 右侧 `col-span-16`：标签统计 + 图鉴网格（独立模式下显示分支标签页）。
4. 联动/独立开关控制：联动时左侧切分支右侧同步，独立时左右可分别选择不同分支。
5. 切换回联动时自动同步右侧分支为左侧当前分支。
