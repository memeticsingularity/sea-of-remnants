# 版本迭代记录

本文档记录 Wiki 项目的版本迭代历史，便于追踪功能演进和内容补充进度。

## 版本号规则

采用 `主版本.次版本.修订号`：

- **主版本**：架构或技术栈重大变更
- **次版本**：新增功能或新增大量内容
- **修订号**：bug 修复、小调整、少量内容补充
